## Featured Project

### Discrete Logic Lab

An interactive SAT solver webpage for a Discrete Mathematics project.

What it does:

- Evaluates Boolean formulas using `AND`, `OR`, and `NOT`
- Shows whether a formula is satisfiable or unsatisfiable
- Generates a full truth table for every variable assignment
- Displays TRUE/FALSE results for each condition
- Includes a clean, responsive user interface

Repository: [discrete-logic-lab](https://github.com/AnnJo94/discrete-logic-lab)
